# JavaScript and TypeScript borrowed results

Plan node: 1219. The [execution receipt](owned-javascript-borrows-20261001.json)
binds compiler inputs, generated adapters, installed npm archives and observed
consumer behavior. Previous receipts remain unchanged.

APIs with parameter-anchored results expose whole `LeanValue<T>` owners.
`share()` keeps the same owner alive; `retain()` copies into an independent owner.
Closing or consuming the last root expires borrowed descendants. Empty arrays,
Lists, None and other empty payloads retain their owner registration. Resource
views compare canonical identity while keeping separate owner lifetimes.

```sh
source scripts/env.sh
LEAN_BRIDGE_NATIVE_TEST_GLIBC_FLOOR=2.36 npm run test:owned-javascript-borrows
```

The enabled gate requires 25 passing tests with no skips or cancellations. Both
ordinary-source and reviewed-IR probes execute 26 exports, including 19 anchored
results and four consuming exports. The shared portable consumer makes 232
assertions. Native allocation and JavaScript construction fault sweeps cover
failures before and after transfer. All tracked owners, allocations and identities
return to zero. Separate borrow-only builds retain empty owners without consuming
exports. Limit tests check 128 borrow edges, 4,096 host wrappers and 64 active calls.

Eight intentionally broken implementations must parse or compile, then fail the
original lifetime assertions. Six change JavaScript root, identity or cleanup
handling; two weaken native revocation during pinned callback reentry. The intact
implementation runs the same assertions before and after those mutations.

The installed CLI builds original npm archives, reproduces them in an independent
build, and verifies deterministic archive reassembly. Offline consumers install
after producer removal. Node, strict TypeScript, Chromium, Firefox and WebKit run
the same package. Every browser exercises a page, React StrictMode and a module
worker twice. The browser checks delete installed sources after bundling and block
external network requests. The consumer documentation example prints `42n`,
`expired`, `42n`. The reviewed build also emits a native C package from the same API.

Production-runtime checks load copied Alpha and freshly compiled borrowed-result
components in both orders on both source paths. They require one runtime
initialization, shared callback execution, independent component closure and zero
remaining identities or handles at shutdown.

The private ABI is version 12; compiled model 9 and owned graph 4 preserve exact
anchor metadata. Earlier unanchored components retain their generated bytes.
CI enforces the enabled TAP totals and preserves all eleven execution reports.

WIT/WASI owner anchors, receiver/callback-result anchors and the final
cross-language Docker audit remain separate work. This receipt does not claim
registry publication or promote unrelated support-table cells.
