# Recursive Kotlin value metadata

The [execution record](kotlin-recursive-values-20260923.json) binds the Kotlin
generator, shared Java conversion engine, compiler configuration and independent
consumer. This check executes 447 assertions and rejects 12 invalid consumer
programs. It does not load Lean or claim installed-package acceptance.

## Public values

Kotlin receives its own sealed constructor families and immutable typed fields.
Nested options retain every absence state. Results retain the active success or
error payload. Primitive arrays use Kotlin primitive-array types; nested arrays
and nominal values retain their element types. Java and Kotlin values remain
distinct nominal types in the same JAR.

Constructors that exceed the JVM argument-slot limit use a typed builder.
The builder requires every field before construction. Its private slots use
erased storage, while setters, immutable result fields and accessors retain their
declared Kotlin types. Builders snapshot field assignments, not mutable array
contents. Native calls return independently copied arrays.

The consumer checks both sides of the constructor-slot limit, the 256-field
recursive constructor and 127 recursive links. Equality, hashing, formatting
and copying reject cycles. Shared acyclic subtrees remain valid.

## Deep metadata

An independent Kotlin compilation consumes generated bytecode with a 32-level
array field. Reflection checks all 32 dimensions and the primitive leaf type.
Graph packages use Kotlin's type-table metadata serialization so the consumer
compiler can decode the complete signature. Ordinary non-recursive packages keep
their existing compiler options.

The compiler-rejection cases cover null payloads, wrong nominal and scalar
types, incompatible options and results, immutable fields, incorrect builder
arguments, inaccessible traversal helpers and nonexistent alias wrappers.
Each rejection must identify the invalid consumer file and expected diagnostic.

## Reproduction

```sh
LEAN_BRIDGE_KOTLIN_GRAPH_TEST=1 \
  node --test tests/jvm-copied-graph-kotlin.test.mjs
```

CI retains `build/recursive/kotlin-values.json`. The
[Maven package tests](../contributing/testing.md#recursive-java-and-kotlin-packages)
separately exercise compiled Lean calls, offline installation and runtime-only
execution through both public APIs.
