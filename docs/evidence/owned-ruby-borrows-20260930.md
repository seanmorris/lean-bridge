# Ruby owner-anchored results

VO1219. RubyGems preserve original-owner function results on ordinary Lean and
reviewed-IR source paths. Ruby uses its checked private C forwarders and isolated
GMP while sharing the compiled Lean component and native runtime.

Resource-containing results use `Value`, including empty containers. `get`
checks the complete owner; `dup` and `clone` share it with separate close guards.
Raw resource views from `get` borrow that owner. Closing the last whole-owner
guard or transferring the original owner expires dependent results transitively.
`retain` and nominal or declaration-selected `copy_value` create independent
ownership. Canonical resource equality raises for expired values.

Transferred inputs pass the original C owner slots. Empty roots participate in
handoff, and reentrant callbacks observe consumed owners immediately. Preflight
errors preserve inputs; errors after handoff leave them consumed. Callback
arguments remain call-scoped and require explicit retention to escape.

The Ruby ownership contract, binding manifest, private adapter receipt and gem
receipt use version 3. The native owned-value transport uses version 4 and binds
`resultAnchors` independently of `inputTransfers`. Unanchored APIs keep their
generated bytes and contract versions.

## Validation

```sh
source scripts/env.sh
LEAN_BRIDGE_NATIVE_TEST_GLIBC_FLOOR=2.36 npm run test:owned-ruby-borrows
```

The host-specific glibc floor does not change the production default or bypass
native symbol checks. The gate requires seven tests with no skips. Both source
paths compile actual Lean, execute borrowed-only and mixed transfer APIs, and
check whole owners, empty values, recursive shapes, callbacks, returned closures,
thread/process affinity and transitive expiration. Allocation fault sweeps retain
exceptions and require no residual bridge allocations or identities after
cleanup. Four executable mutations must fail independent assertions.

Installed-gem checks remove producer sources before offline installation,
authenticate lifetime contracts and native artifacts, execute public-only
callers and the documentation example, and reject incapable readers. Reassembled
archives must be byte-identical. Consumers run again after handoff and cache
deletion and relocation. Loader probes cover concurrent requires, fork with a
held loader lock, private GMP and altered libraries. The reviewed build also
installs C++, Cargo and PyPI consumers of the same compiled component.

The JSON receipt records observed outputs and exact source transitions without
rewriting earlier receipts. No installed support-table cells are promoted here.
Docker acceptance, receiver anchors, callback-result anchors and the remaining
consumer projections are separate work. No registry upload is performed.
