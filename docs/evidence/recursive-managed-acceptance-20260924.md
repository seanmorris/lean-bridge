# Installed recursive values in C#, Java, Kotlin and PHP

Copied recursive values have installed acceptance in sixteen of the seventeen
consumer profiles. This stage adds C#, Java, Kotlin, native PHP and PHP-Wasm:
thirty cells covering inputs, results and fields on both ordinary-source and
reviewed-IR paths. Inventory 0.84.0 records 4,212 installed cells out of 6,562.

The [acceptance index](recursive-managed-acceptance-20260924.json) binds fourteen
original package artifacts, their complete execution records and the current
shared-backend regressions. It does not rebuild or rewrite historical receipts.

- [C#](dotnet-current-graph-packages-20260924.md): original NuGet archives,
  runtime-only consumers, concurrent calls, compiler rejections, independent
  reproduction and shared-runtime lifecycle checks.
- [Java and Kotlin](jvm-recursive-packages-20260923.md): both generated APIs,
  offline Maven resolution, runtime-only execution, nominal constructor and
  null checks, independent reproduction and class-loader conflicts.
- [Native PHP](php-recursive-packages-20260923.md): original Composer archives,
  weak and strict callers, compiler-free relocated execution, independent
  reproduction and runtime retirement.
- [PHP-Wasm](php-wasm-recursive-packages-20260924.md): installed npm descriptors
  and Composer files, startup and first-call loading, Node and Chromium callers,
  plus [independent reproduction and shared loading](php-wasm-recursive-loading-20260924.md).

Consumer tables now show the accepted copied positions. Exact source comparisons
preserve every executed documentation example while allowing these reviewed
table and status changes. Tests reject missing profiles, a missing authoring
path, altered archive identities, unrelated edits and callback overclaims.

WIT/WASI recursive values, structured callback/closure payloads and explicitly
owned resource-containing aggregates remain open. This stage does not complete
VO1219 or the full structured-types goal.
