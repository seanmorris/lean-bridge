# C# owner-anchored results

VO1219. NuGet packages preserve original-owner function results on ordinary Lean
and reviewed-IR source paths. C# uses the checked private C adapter, isolated GMP
and the shared compiled Lean component and native runtime.

Resource-containing results use `Value<T>`, including empty containers. `Get`
checks the complete owner and returns borrowed resource views. `Share` adds a
guard for the same owner. Disposing the last guard or transferring that owner
expires dependent results transitively. `Retain`, `Api.CopyValue` and
declaration-selected copy factories create independent ownership. Resource
equality compares canonical native identities and rejects expired values.

Transferred arguments pass the original native owner slots. Empty roots
participate in handoff; callbacks observe consumed owners immediately. Preflight
errors preserve inputs. Errors after handoff leave them consumed. Callback
arguments remain call-scoped and require explicit retention to escape.

The ownership contract, binding manifest, private adapter, compiled assembly
receipt and NuGet package receipt use version 3. The native owned-value transport
uses version 4 and authenticates `resultAnchors` separately from `inputTransfers`.
Unanchored APIs retain their generated bytes and contract versions.

## Validation

```sh
source scripts/env.sh
LEAN_BRIDGE_NATIVE_TEST_GLIBC_FLOOR=2.36 npm run test:owned-dotnet-borrows
```

The host-specific glibc floor keeps native symbol verification enabled. The gate
requires seven tests without skips. Both source paths compile actual Lean and
execute borrowed-only and mixed transfer APIs. Runtime checks cover whole
owners, empty values, recursion, callbacks, returned closures, thread affinity,
thread-exit cleanup, garbage collection and transitive expiration. Managed and
native allocation fault sweeps retain thrown exceptions and require zero
remaining native allocations and identities. Four compiled mutations must fail
independent runtime assertions.

Installed consumers use only public C# with unsafe code disabled. Sixteen
ill-typed programs must fail compilation against the installed assembly. The
gate executes the exact documentation example, rejects altered contracts and
native libraries, and requires byte-identical package reassembly. Producer
sources are removed before offline installation. Consumers run again after
handoff, package cache and consumer-source removal, relocation and replacement
of the SDK with the standalone .NET runtime. The reviewed build also installs
C++, Rust, Python and Ruby consumers of the same compiled component.

The JSON receipt records observed outputs and exact source transitions without
rewriting earlier receipts. No support-table cells are promoted by this record.
Borrow-specific Docker and inherited-process checks, receiver anchors,
callback-result anchors and the remaining consumer projections are separate
work. No registry upload is performed.
