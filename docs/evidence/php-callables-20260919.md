# Native PHP primitive callbacks and returned Lean functions

The installed consumer passes 51,686 assertions in weak and strict PHP caller
modes on each source path. Each mode runs twice after relocation. The
[acceptance record](php-callables-20260919.json) binds those runs to the original
Composer archives, exact Brick Math dependency, PHP sources and loaded libraries.

## Public API and ownership

The 63-export library covers all nineteen primitives, mixed callback signatures,
multiple callbacks, captured values and sixteen-argument functions. PHP accepts
callables with precise generated PHPDoc. Returned `LeanClosure` objects are
invokable, with `isClosed()` and idempotent `close()`. Public parameters stay
`mixed` so the bridge can reject coercion even from weak callers.

Nat, Int, UInt64 and native USize retain `Brick\Math\BigInteger`; Unit uses null,
Char uses one UTF-8 scalar, and ByteArray uses the generated Bytes value.
No new dependency, public FFI declarations or private C ABI changes are needed.

The adapter catches callback `Throwable` failures and rethrows the same object
after native cleanup. Trace, previous exception and first-failure behavior are
preserved. Copied callback arguments remain valid after the call; the host
function itself is borrowed for that call only. Expired native borrows reject.

[PHP's FFI callback documentation](https://www.php.net/manual/en/ffi.examples-callback.php)
notes request-lifetime resource retention. This adapter caches one trampoline
per signature and stores callers in separate call-scoped contexts. The
trampoline captures no caller, scope or result buffer. Completed calls remove
their context and release copied storage, including after conversion failures.

Closures own their native token, reject calls after closing and defer release
while active. Destruction is a fallback; saved first-class callable aliases
retain the same wrapper. Direct construction, cloning and serialization reject.
Callable entry from a Fiber rejects. The native package supports NTS CLI;
post-fork calls and closes reject before native entry, and child destructors
skip inherited leases. Installed tests fork the real PHP interpreter after
native calls; the lifetime-state test also substitutes a controlled guard.

## Acceptance checks

- Signed/unsigned endpoints, 31/32/53/64-bit boundaries and 16,385-bit integers.
- Float32 rounding, signed zero, subnormals, NaN classification and infinities.
- Unicode scalars, embedded NUL, combining marks, noncharacters and all bytes.
- Independent callback copies, exception identity and forced cyclic GC.
- Invalid types, unsigned ranges, negative Nat, malformed UTF-8, callback
  results and oversized copies, checked from weak and strict callers.
- Reentry-limit failure and recovery, expired borrows, aliases and destruction.
- All 4,096 closure identities held concurrently, exhaustion, release and
  8,192 subsequent leases. A warmed 20,000-call run checks retained PHP memory.
- Deferred active close, fiber rejection and post-fork rejection.

Composer installs the exact prepared ZIP and brick/math 1.0.0 with an empty
home/cache, networking disabled, plugins/scripts disabled and a locked repeat
install. The harness relocates vendor, removes its installation project and
runs with INI disabled, explicit FFI, no compiler PATH or runtime overrides.
Deployment hashes stay unchanged. All four loaded Lean/adapter libraries must
come from that installed package and match its receipt.

Independent Shop/Telemetry Lean oracles cover 124 copied-value catalog cases
per source path, repeated in weak/strict modes. The Clover/Juniper regression
suite checks reproducible Composer/C archives, copied values, conversion-failure
cleanup, tamper rejection, shared loading, cross-package callbacks/closures,
nested exception identity, fork rejection and atomic build failures.

Local acceptance uses PHP 8.2.33 NTS CLI, Composer 2, GCC 12.2.0 and glibc 2.36.
The declared package/CI glibc floor remains 2.38. Each native adapter permits
64 nested calls per thread; the shared runtime permits 4,096 closure identities.
Conversion limits do not bound PHP or Lean heap allocation. Server SAPIs, ZTS,
PHP-Wasm, compound callables, resources and async are outside this milestone.
