## Installed routes

The ordinary-source and independently reviewed routes each build a fresh Lean
component, reproduce the runtime and component npm archives, remove the author
source and component build, and install the archives offline. The installed
Node caller accepts valid values through two independently selected checked
constructors, rejects a negative `Int` before dispatch, uses the same resource
after both rejections, disposes it and closes the component. Strict TypeScript
keeps the erased field as `bigint` and rejects `number`.

Static pages, React Strict Mode and dedicated workers execute from source-free
bundles in Chromium, Firefox and WebKit. Each of the nine engine/profile lanes
runs twice after its initial execution, loads exactly the two installed
WebAssembly assets and blocks external network requests. The machine-readable
[acceptance record](owned-subtype-javascript-acceptance-20261020.json) retains
the component, Binding IR, source, package-set, archive and WebAssembly
identities for both author routes.

## Boundary

This evidence establishes borrowed parameters containing the fixture's acyclic
owned `Bundle`, resource identity, a copied payload with
`{ count : Int // 0 ≤ count }`, exact constructor rejection and proof-free
results. It does not establish explicit retain or transfer modes, refined owned
callbacks, recursive owned mirrors, generic records, other predicates, other
consumer languages, dispatch cost or memory bounds. Those combinations remain
separate acceptance work.
