# Recursive C and C++ callbacks

Plan node: 1219. Baseline: `136e4942ed32bd923cb721eb80aa038cfaa07f74`.

Prepared C11 and C++20 packages accept finite recursive copied callback values
and returned closures on both ordinary-source and independently reviewed paths.
The package fixture has 33 exports covering nine copied shapes and two nested
alias signatures. Consumers install relocated original archives after the author
sources have been removed. Sanitized executables repeat after removal of the
headers, consumer source and archive handoff.

| Check, per source path | Observed result |
| --- | --- |
| C installed consumer | 10,207 checks, 708 callbacks, 52 rejected edge cases |
| Instrumented C consumer | 217,706 checks; 1,974 native and 5,328 GMP-facade allocation failures |
| C++ installed consumer | 14,073 checks; 8,992 injected allocation failures |
| C++ invalid callers | Seven type errors rejected by the compiler |
| Mixed C/C++ executable | 421 checks in each include order; one runtime, one component, zero remaining identities |
| Native carrier probe | 26,746 checks, repeated under ASan/UBSan |
| Native exported-call probe | 68,613 checks, repeated under ASan/UBSan |

C failure probes restore the allocation ledger after every checkpoint and finish
with zero tracked allocations. Removing either argument-arena or reply-owner
cleanup makes the probe fail. Native probes also reject deliberately omitted
closure disposal and writes to failed outputs. Public C/C++ leak checks preserve
the existing GMP startup baseline of 128 bytes in 12 allocations.

The edge cases include all 64 accepted depths of the tree fixture and its first
rejected depth, invalid UTF-8, negative `Nat`, invalid active tags, null or
oversized spans, cycles, unchanged failed outputs and active closure disposal.
The C probe checks foreign processes and 17 foreign-thread cases, including
threads created after the closure's creator exits. C++ checks 16 departed-creator
cases. Native closure leases now use thread-lifetime serials rather than reusable
operating-system thread IDs. Exhausting the serial range rejects new leases.

The C and C++ publisher/consumer examples compile on both source paths, install
offline and print `43` twice from runtime-only deployments. Consumers use GMP
values and bounded `TYPE_copy` helpers in C, or named variants and owned standard
containers in C++. They do not construct Lean objects, constructor numbers or
JSON transport messages.

Graph conversion limits are 128 value edges, 262,144 nodes and 16 MiB of native
copied storage. Host conversion has its own 16 MiB budget. Callable nesting is
limited to 64 active invocations, and closure leases share 4,096 runtime identity
slots. These limits do not bound the Lean algorithm's own allocation. The tree
fixture uses an array edge at each branch, so 64 accepted tree depths do not mean
a separate 64-level graph limit. GMP retains its default fatal allocation policy.

The copied-value regression compares complete 32-bit and 64-bit native adapters
against the baseline. Their generated bytes are unchanged. Public package changes
are limited to a shared status-header guard and namespacing private C++ ABI types
so C and C++ headers can coexist.

Reproduce installed acceptance:

```sh
LEAN_BRIDGE_NATIVE_RECURSIVE_CALLABLE_TEST=1 \
LEAN_BRIDGE_C_RECURSIVE_CALLABLE_TEST=1 \
LEAN_BRIDGE_CPP_RECURSIVE_CALLABLE_TEST=1 \
node --test --test-concurrency=1 \
  tests/native-recursive-callable-compile.test.mjs \
  tests/c-recursive-callable-package.test.mjs \
  tests/cpp-recursive-callable-package.test.mjs

LEAN_BRIDGE_C_FAMILY_RECURSIVE_DOCUMENTATION_TEST=1 \
node --test tests/c-family-recursive-documentation.test.mjs
```
