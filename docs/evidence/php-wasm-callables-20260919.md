# PHP-Wasm primitive callbacks and returned Lean functions

The installed callable consumer passes 79,934 assertions in each of 24
configurations. Ordinary-source and independently reviewed packages each run
weak and strict PHP callers with startup and lazy loading. Node checks both
the npm-embedded PHP API and Composer autoloading; Chromium checks Vite-bundled
packages. The [acceptance record](php-wasm-callables-20260919.json) records the
archive identities, source hashes and per-configuration results.

## Public API and lifetime

The 63-export library covers nineteen primitive types, captured values, mixed
signatures, multiple callbacks and sixteen-argument functions. PHP accepts
synchronous callables with generated signature PHPDoc. Returned `LeanClosure`
objects are invokable and expose `close()` and `isClosed()`. Mixed bridge
parameters prevent weak callers from silently coercing input values.

This compiled Lean target has 32-bit words. UInt32, UInt64, Int64, Nat, Int and
USize use exact `Brick\Math\BigInteger` values. ISize uses a range-checked PHP
integer. Unit uses null, Char uses one UTF-8 scalar, and ByteArray uses the
generated Bytes class. The installed application needs no FFI declarations or
Lean compiler.

The Zend adapter preserves the first callback `Throwable`, including its
identity, trace and previous exception. Copied arguments survive the call;
the callback itself is borrowed for that call only. If a callback calls
`exit()`, Zend defers the bailout until Lean releases its active frame.
Each installed configuration verifies that later requests still work.

Zend resources own returned functions. Saved callable aliases retain the
same lease. Closing is idempotent and defers disposal while the lease is
active; destruction supplies a fallback. Calls after close, direct
construction, cloning and serialization reject.

The runtime keeps borrowed callback tokens within 32 bits and retires exhausted
generations. Returned-function leases retain the shared broker's full 64-bit
identity separately from their non-reused 32-bit local token. Production-registry
tests check expiry, release, active references and exhaustion near the integer
limits. The native 64-bit registry's generated source remains unchanged.

## Acceptance checks

- Signed and unsigned endpoints, 31/32/53/64-bit boundaries and 16,385-bit
  arbitrary integers, including captured and returned values.
- Float32 rounding, signed zero, subnormals, NaN classification and infinities.
- Unicode scalars, embedded NUL, combining marks, noncharacters and all bytes.
- Wrong types, ranges, negative Nat, malformed UTF-8, invalid callback results,
  excessive copies, reference parameters/returns and generator callbacks.
- Original exception identity, nested callbacks, reentry-limit recovery,
  expired borrows, destructor recovery and forced cyclic GC.
- All 4,096 owned identities held concurrently, exhaustion, release and 8,192
  subsequent leases. A warmed 20,000-call run checks retained PHP memory.
- A callback bailout followed by a request making 70 calls, each nested twelve
  levels deep.

The harness verifies the package-set receipt, removes author sources before
installation, installs npm and Composer archives offline, relocates the
application and executes without compilers on PATH. Each run observes one
shared runtime and one component library.

Fresh Shop and Telemetry Lean oracles cover 124 copied-value catalog cases on
each source path through all twelve PHP-Wasm configurations. The Willow/Aspen
regression builds 46 exports per package twice, reproduces npm and Composer
archives, and checks shared loading, cross-package closures, nested exception
identity and recovery. The native PHP callable suite and existing Zend
allocation-failure/bailout tests also pass.

```sh
LEAN_BRIDGE_PHP_WASM_CALLABLE_TEST=1 node --test tests/php-wasm-callables.test.mjs
node --test tests/php-wasm-callable-contract.test.mjs
LEAN_BRIDGE_PHP_WASM_ORDINARY_TEST=1 LEAN_BRIDGE_PHP_WASM_BROWSER_TEST=1 \
  node --test tests/php-wasm-ordinary.test.mjs
npm run test:type-corpus:php-wasm
LEAN_BRIDGE_REVIEWED_WASM_PROFILES=php-wasm node --test tests/type-corpus-reviewed-wasm.test.mjs
```

Acceptance uses PHP 8.4.1 in php-wasm 0.1.0, Emscripten 3.1.68, the pinned
Lean 4.32.2 toolchain and Chromium 152.0.7977.75. Each adapter permits 64 nested
calls; the shared runtime permits 4,096 owned identities. Conversion budgets
are 16 MiB, not limits on the PHP or Lean heap.

The pinned PHP-Wasm host cannot start Fibers. A separate native PHP test
executes the generated Zend lease's Fiber guard and deferred-close behavior.
This milestone does not add compound callables, resources, async operations
or reviewed copied-field coverage. Older prepared PHP-Wasm compiler inputs
must be rebuilt with the callback registry before compiling callable exports.
