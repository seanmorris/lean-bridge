# JavaScript and TypeScript methods and properties

Acceptance requires `npm run test:owned-javascript-receivers` to pass all 28
tests without skips. The execution receipt binds that run to 23 reports and
the exact sources that generated the packages and probes.

The JavaScript wasm32 adapter exposes named whole-value owners with methods
and read-only properties. TypeScript carries those member types through
`share()` and `retain()`. Borrowed results follow the original receiver or
remaining-argument owner. Consuming methods invalidate the original owner's
shared roots and descendants before Lean runs.

The gate executes all 16 members and the predecessor's 232 lifetime checks on
both ordinary and reviewed source. Fault sweeps retain exceptions while
checking native owners, allocations, identities and callbacks return to zero.
Real garbage collection covers original owners, payload cycles and retained
method references. Twelve parsed or compiled semantic mutations must fail
their named assertions; the restored implementation must pass again.

Installed CLI builds produce source-free offline npm releases. Node,
TypeScript, Chromium, Firefox and WebKit execute the generated APIs, including
pages, React and workers. Resource-only packages with and without transfers,
and callback packages without result anchors, have separate installed checks.
Independent builds and reassembly must reproduce both archives. The full
package test executes the exact consumer documentation example.

Receiver owners and copied Alpha handles share one runtime in both load
orders. Closing a component invalidates its members without closing the
other component; final shutdown prevents subsequent loads.

This milestone does not add callback-result lifetimes or claim the final
cross-language container audit. It preserves historical receipt bytes and
does not promote unrelated support-matrix cells.
