# Acceptance records

This directory stores versioned inputs for clean-room and zero-configuration acceptance checks.

- [`clean-room-sessions.v1.json`](clean-room-sessions.v1.json) records the reviewed clean environment sessions.
- [`zero-config-audit.v1.json`](zero-config-audit.v1.json) defines the zero-configuration audit result.
- [`time-to-package-budgets.v1.json`](time-to-package-budgets.v1.json) retains the versioned time-to-package comparison inputs used by existing tooling.

Schemas live in [`../schema`](../schema/README.md). Human-readable results live in [zero-configuration evidence](../docs/evidence/zero-configuration-acceptance.md) and the [clean-room usability protocol](../docs/evidence/clean-room-usability-protocol.md).
