A game can have thousands of objects, but most are nowhere near each other. Sweep-and-prune uses one axis to discard separated pairs, then checks the remaining boxes on every axis.

How to read it

One axis first.
Every axis next.

  1. 1
    Drag any box

    Start with A and B. Their horizontal spans overlap, but there is a gap between them vertically.

  2. 2
    Follow the projection

    The strip places each box on the chosen axis. Overlapping spans become candidate pairs.

  3. 3
    Check the other axis

    C and D overlap in both directions. Lean keeps that pair and rejects candidates that still have a gap.
